## 授权与范围

用户在本任务回复“确认”，同意一次本机 HTTPS 采样，范围为本人手机中北京 114 官方首页、医院、科室和排班查询。可以临时设置代理和安装测试证书；不访问订单、报告或患者管理，不选择就诊人，不提交挂号或付款。

若客户端拒绝测试证书或存在证书固定，停止采样并恢复；不 root、hook、改包或绕过校验。证书由用户在手机系统的正常安装流程中确认。本次授权不等于任何后续真实预约授权，也不改变 v0.2 仅设计和本地保留的边界。

## 临时文件与恢复方式

工作目录：`/tmp/guahao-v02-capture-20260925`，权限为 0700。独立虚拟环境、CA 私钥、设置基线和工具脚本均在此目录，不加入 Git。原始 HTTP 凭据不写磁盘，命中请求只在代理处理时经过内存；输出仍须复核后才进入本地研究证据。

手机证书文件：`Download/Guahao-114-20260925-1040.cer`。应通过手机“安装 CA 证书”正常系统流程安装；退出验证后在用户凭据中只删除本次同名测试 CA，不能清空其它凭据。

若 USB 断开导致自动恢复失败，先重新连接原手机，再执行：

```sh
/tmp/guahao-v02-capture-20260925/runtime/bin/python \
  /tmp/guahao-v02-capture-20260925/device_proxy.py restore
```

恢复验收须包括：五个代理键与基线一致、USB reverse 与基线一致、本机代理进程退出、用户确认本次 CA 已移除、手机下载证书与本机 CA 私钥已删除。未完成时逐项保留为待处理，不能笼统写“清理完成”。
