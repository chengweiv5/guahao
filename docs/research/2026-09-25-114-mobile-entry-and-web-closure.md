日期：2026-09-25。仅本地保留；不推送。结论：**用户已到达微信中的业务首页，复制链接路径不适用；普通网站预约已由平台公告关闭。移动 API 与独立认证仍未验证。**

## 1. 用户截图已经证明什么

用户提供 `20260925-102319.jpeg`，明确表示没有复制链接功能。截图可见页面标题“北京市预约挂号统一平台”、域名 `www.114yygh.com`、个人中心的脱敏身份、医院/科室/医生搜索、“全部医院 共309家医院”，以及展开的微信菜单。

菜单有星标、搜一搜、浮窗、保存为图片、投诉、刷新、查找页面内容和全文翻译，未显示复制链接或分享入口。因此取消此前要求用户复制页面链接的前置条件，不再重复要求查找不存在的选项。只据截图记录“当前可见菜单没有”，不推断全部微信版本或所有页面均禁止分享。

这是手机业务 UI 可达的证据；不能从截图取得完整路径、Cookie、API、匿名可读性或服务端会话有效性。“309”是这张截图的页面显示值，不是已枚举的医院数，也不是本 App 已支持医院数。原图留在用户桌面，不复制进仓库或通知；本地证据只记哈希与脱敏观察。

## 2. 正常 Chrome 已确认网站预约关闭

绕开前次不可用的 Chrome 连接器，使用原生 Chrome UI 打开独立标签，正常加载 `https://www.114yygh.com/`，没有关闭安全保护、求解验证码或重放校验脚本。页面显示官方公告：

> 北京市预约挂号统一平台已于2023年12月08日起关闭网站预约渠道（www.114yygh.com）。

同页指引继续使用：

1. “北京114预约挂号”微信公众号。
2. 微信、支付宝、百度中的“京通”小程序，选择健康服务。
3. 010-114 电话预约。

通过正常浏览器“查看网页源代码”核实公告图片是第一方资源 [cont.png](https://img.114yygh.com/image/web-offline/cont.png)，独立下载和目视再次核对原文。公开原图已保存到[本地证据](evidence/2026-09-25-beijing/114-web-offline-notice.png)，SHA-256 为 `7e849891ff386711bc5beaea27c90c0871e48270ca646e9a242c6ed2ea6f957e`。

这修正了前次“仅知桌面校验受阻”的结论：校验壳仍是此前独立 HTTP/IAB 的实际响应，但普通 Chrome 正常页面进一步提供了业务关闭原因。手机截图虽然显示相同域名，不能因此认为网站公告也关闭了微信业务入口。

本轮打开设备预览菜单后，具体手机配置选择未完成，未获得独立的移动 User-Agent 访问结果；该项不记通过。已退出设备预览、关闭 DevTools 和本轮独立标签，恢复浏览器设置。

## 3. 手机技术通道只读检查

宿主 ADB 发现一台 USB 连接的 Huawei ALN-AL00 和一个模拟器。仅用 `adb -d` 对唯一物理 USB 设备检查公开调试 socket，`webview_devtools_remote / chrome_devtools_remote / xweb_devtools_remote` 匹配数为 0。设备序列号不保存。

这只能证明当次没有可枚举的标准网页调试 socket，不能证明微信绝无其它调试实现。没有读取微信私有文件、Cookie、消息、用户订单；没有启用隐藏调试、安装证书、设置代理、操作手机页面或改变手机状态。

## 4. 设计修正

- 北京 114 的首批技术目标明确为**官方移动渠道**；网站首页仅作为官方说明来源，不再作为预约实现或认证 fallback。
- “从微信复制链接导入 App”不作为 114 的必需接入流程。佑安服务号既定方案属于另一平台，不照搬到 114。
- 将“手机业务 UI 可见”“本地程序能够独立认证”“医院/排班 API 可读”“自动提交可验证”分开记录；当前仅新增第一项证据。
- 首次接入和失效恢复必须由平台实际支持的认证方式验证；没有可用 API 认证前，自动挂号能力保持关闭。

## 5. 下一步可行验证与所需决定

界面级验证可以由用户在现有官方页面打开目标医院、科室与排班，继续验证实际 UI 和医院差异，不触发预约确认。

底层接口目前缺少正常可用的网络观测通道。若用户同意进行一次限定范围的本机 HTTPS 采样，计划仅观察本人在官方微信页面的一次首页刷新、搜索“北京大学人民医院”、进入普通门诊科室/排班；不访问我的订单、报告或患者管理，不选择就诊人，不点击预约确认。目标域名先依据真实流量核对，仅对官方 114 所需域名开启采样，不扩大到其它 App 或服务。

此步骤可能需要临时设置该手机 Wi-Fi 代理和信任测试证书，会使本机代理接触命中流量中的会话凭据；原始样本仅放本机受限临时目录，分析后只保存端点、字段名及脱敏结构，不上传、不推送，完成后恢复代理、移除测试证书和删除临时凭据。若微信不接受测试证书或有证书固定，立即停止，不 root、不 hook、不改包、不绕过校验。
