# 后续开发计划候选

记录日期：2026-09-25。

以下为用户提出的后续开发候选，均未排期；优先级、目标版本和具体实现方案待后续确定。

| 候选方向 | 内容 | 状态 |
| --- | --- | --- |
| 扩展医院 | 增加其他医院，例如北京宣武医院。 | 候选，未排期 |
| 北京通用挂号平台 | 调研并支持北京通用的挂号平台接口，以覆盖更多医院的挂号需求。 | 候选，未排期 |
| 接口来源可选 | 支持用户选择接口来源，例如微信服务号、互联网医院、114 挂号平台。 | 候选，未排期 |
| 扩展其他城市 | 调研并支持其他城市的挂号平台接口。 | 候选，未排期 |

当前 v0.1 的需求与范围见 [v0.1 需求与实现方向](design/2026-09-24-v0.1-requirements-and-approach.md)。
