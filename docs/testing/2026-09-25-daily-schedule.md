# 按日期排班与预选医生验证

2026-09-25，用户确认界面设计后要求继续实现。Android 调试版已保留数据覆盖安装到华为 Mate 60 Pro，HarmonyOS 4.2；未推送。

## 实现结果

- 新建任务按科室 → 就诊日期 → 查询当日排班 → 医生的顺序进行。有目标日排班时只列当天医生；缺少当天医生时提供“预选目标医生”，身份来自服务号已返回的本科室名单。预选不显示其他日期的费用或时段。
- 佑安适配保留日期原始状态：`1` 当日有号、`0` 当日无号、`-2/-3` 尚未放号，其他值或缺少日期为未知。空医生列表、查询失败、用户计划查号时间均不作为号源状态依据。
- 医生目标日排班是否确认独立保存。确认页、任务卡、详情页显示最近查询状态、时间及待确认标记。换日期、科室、就诊人或就医目的后清空旧选择，取消旧查询；返回上一页保留本次选择。
- 执行时重查目标日。未放号、无号、未知、科室不匹配或医生未确认都不会提交；只匹配原指定医生、科室、日期、时段、费用和执行截止时间，不自动换医生。单笔提交、结果核对和支付路径沿用原有保护。
- 可选 JSON 字段兼容旧任务；数据库仍是 v2。界面使用现有日期选择器和滚动表单。
