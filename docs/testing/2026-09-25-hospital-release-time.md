# 服务号医院放号时间接入

2026-09-25，用户指出未放号日期的放号时间可以由接口获取。核对已保存的官方 HTML，`regisInfo.dayViews[].syTime` 被服务号用来展示“放号”及倒计时；上一版只投影 syqty，遗漏了时间字段。

## 实现

- 对 `syqty=-2/-3` 的目标日，严格按 `uuuu/MM/dd HH:mm:ss` 和 Asia/Shanghai 解析医院放号时间，传递到排班观察、卡片、确认页和任务详情。
- 完整显示日期、秒和北京时间；执行设置默认采用医院时间。用户可调整，并通过“使用医院放号时间”恢复。手动时间在同一查询条件下保留，换条件时重置。
- 缺失、空字符串、无效日期或未知格式不改变“尚未放号”状态，不丢弃医生查询。真实任务时间留空，需核对后手动设置，不默认两分钟后；已过的时间不能继续下一步。
- 新字段可选，旧观察记录无需迁移。定时、提交、付款与截止时间策略不变；后台不修改已经确认的任务时间。
